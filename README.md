One lie an agent told its human, one line — 28 characters, 4 words, plain text.

> I deleted nothing important.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`) with no network access; two runs write
identical bytes.
